# Turn-Level Importance Sampling Implementation Guide

## 📋 Overview

This implementation extends the PPO policy loss computation to support multiple levels of importance sampling, including the new **turn-level importance sampling** feature.

## 🎯 Importance Sampling Levels

### 1. Token-level (Default)
```python
importance_sampling_level = 'token'
```
- Each token uses its own importance weight
- Traditional PPO behavior
- Formula: `w_{i,t} = exp(log_prob_{i,t} - old_log_prob_{i,t})`

### 2. Sequence-level  
```python
importance_sampling_level = 'sequence'
```
- All tokens in sequence share the same importance weight
- Weight is the average over the entire sequence
- Formula: `w_i = exp(1/T * Σ_{t=1}^T (log_prob_{i,t} - old_log_prob_{i,t}))`

### 3. Partial-Sequence-level
```python
importance_sampling_level = 'partial_sequence'
```
- Each token at position t uses cumulative average from position 1 to t
- Inspired by GRPO methodology
- Formula: `w_{i,t} = exp(1/t * Σ_{s=1}^t (log_prob_{i,s} - old_log_prob_{i,s}))`

### 4. Turn-level (NEW) 🆕
```python
importance_sampling_level = 'turn'
turn_indices = batch['turn_indices']  # Required
```
- All tokens within the same turn share the same importance weight
- Weight is the average of log_ratios within each turn
- Formula: `w_{i,turn} = exp(1/|turn| * Σ_{t∈turn} (log_prob_{i,t} - old_log_prob_{i,t}))`

## 🔧 Implementation Details

### Core Function Signature
```python
def compute_policy_loss( 
    old_log_prob,
    log_prob,
    advantages,
    eos_mask,
    cliprange,
    detach_ratio='soft',
    importance_sampling_level='token',  # NEW parameter
    turn_indices=None,                  # NEW parameter
):
```

### Turn Indices Format
The `turn_indices` tensor has shape `(batch_size, max_indices)` and stores turn boundaries as:
```
[start1, end1, start2, end2, start3, end3, ..., -1, -1, -1]
```

Example:
- Turn 1: tokens 863-1491
- Turn 2: tokens 2114-2132  
- Storage: `[863, 1491, 2114, 2132, -1, -1, ...]`

### Turn-Level Algorithm
For each batch sample:
1. Extract valid turn indices (≠ -1)
2. Parse into (start, end) pairs
3. For each turn:
   - Calculate average log_ratio for tokens in that turn
   - Assign this average to all tokens in the turn
4. Compute importance weights: `ratio = exp(log_importance_weights)`

### Manual Usage
```python
import torch
from verl.trainer.ppo import core_algos

# Your data
old_log_prob = torch.randn(2, 10)
log_prob = torch.randn(2, 10) 
advantages = torch.randn(2, 10)
eos_mask = torch.ones(2, 10)
turn_indices = torch.tensor([[1, 3, 5, 7, -1, -1], [0, 2, 4, 8, -1, -1]])

# Compute loss with turn-level importance sampling
pg_loss, pg_clipfrac, ppo_kl = core_algos.compute_policy_loss(
    old_log_prob=old_log_prob,
    log_prob=log_prob,
    advantages=advantages,
    eos_mask=eos_mask,
    cliprange=0.2,
    detach_ratio='soft',
    importance_sampling_level='turn',
    turn_indices=turn_indices
)
```

## 🔍 Key Features

### 1. Automatic Fallback
- If turn_indices is invalid, falls back to token-level
- Handles edge cases gracefully

### 2. Boundary Checking  
- Ensures turn positions are within sequence bounds
- Validates turn_indices format

### 3. Mask Awareness
- Only considers valid tokens (where eos_mask=1) 
- Respects attention masks and padding

### 4. Debug Information
- Prints importance sampling level being used
- Shows detachment strategy and clip range

## 📊 Benefits of Turn-Level Importance Sampling

1. **Semantic Coherence**: Groups tokens by semantic turns rather than arbitrary positions
2. **Reduced Variance**: Shared weights within turns can reduce gradient variance  
3. **Better Alignment**: Aligns importance weighting with natural conversation structure
4. **Flexible Control**: Can be easily switched between different levels via configuration
